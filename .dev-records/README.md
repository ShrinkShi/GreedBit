# 开发过程记录

本目录记录 GreedBit 开发过程中的关键节点、技术决策、问题排查、变更、经验与待办，用于复盘、写 README / release、以及后续接手时恢复上下文。

## 记录原则

- 只记录有复盘价值的信息，不记录聊天原文。
- 不记录密钥、密码、token 等敏感信息。
- 不把猜测写成事实；未确认的根因明确标注。

## 文件说明

| 文件 | 用途 |
|---|---|
| `timeline.md` | 时间线，记录每轮关键开发过程 |
| `decisions.md` | 技术决策与取舍 |
| `issues.md` | 问题现象、根因、解决方案 |
| `changes.md` | 每轮实际改动 |
| `lessons.md` | 可复用经验 |
| `backlog.md` | 未完成事项 |
