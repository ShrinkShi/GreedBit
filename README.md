# GreedBit

GreedBit 是一个本地运行的虚拟货币交易模拟器。交易账户、订单、杠杆、资产划转和盈亏结算仍然是模拟系统，但 **BTC/USDT 与 ETH/USDT 的市场行情已经接入真实公开数据**。

当前版本：**v0.0.8**

## v0.0.8 重点

### 真实 BTC / ETH 市场行情

当前仅保留：

- BTC/USDT
- ETH/USDT

行情来源：

- Binance Spot REST API：历史 K 线、24H 统计、盘口深度
- Binance Spot WebSocket：实时成交与 24H ticker

历史 K 线直接读取真实交易所 OHLCV 数据；当前 K 线由实时成交继续更新，不再使用本地随机市场生成器。

10 分钟周期由真实 5 分钟 K 线聚合得到，其余常用周期直接读取对应交易所周期。

如果 Binance 在当前网络或地区不可访问，GreedBit 会显示真实行情连接失败，并停止依赖市场价格的下单，不会回退到随机假行情。

### 图表坐标升级

- 横坐标时间同时显示日期与时间
- 深度放大后会显示秒级时间
- 横轴缩放移除原先 `3 ~ 6000` 根 K 线限制
- 纵轴缩放移除原先 `0.0005 ~ 5000` 倍限制
- 横纵轴均使用连续指数缩放
- 支持上下、左右拖动画布
- 双击恢复默认视图
- 纵坐标最低价格固定为 `0`
- 不允许图表显示负价格
- 向左查看超出已加载历史时，会按需继续加载更早的真实 K 线

### 真实盘口

盘口不再根据当前价随机生成，而是读取 Binance 公开深度接口。

### 新闻系统与真实行情的关系

v0.0.7 中本地随机新闻会修改模拟市场漂移和波动率。

从 v0.0.8 开始，由于 BTC / ETH 行情切换为真实外部市场数据：

- 新闻仍保留真假消息、待核实、已确认、已证伪
- 用户仍可点击“利好 / 利空”
- “其他用户评价”仍为本地模拟
- **新闻不再直接修改 BTC / ETH 市场价格**

否则就无法保证显示的是实际市场行情。

## 交易功能

### 现货

- 市价买入 / 卖出
- 限价买入 / 卖出
- 不支持做空
- 独立现货账户
- 现货限价委托显示在 K 线图

### 合约

- 开多 / 开空
- 全仓 / 逐仓
- 1X–200X 杠杆
- 限价委托
- 止盈 / 止损
- 强制平仓
- 模拟资金费率
- 历史仓位与财务流水

> 合约只是游戏规则模拟。市场价格虽然来自真实现货行情，但强平、手续费、资金费率和风险参数不代表任何真实交易所。

## 分账户资产

- 现货
- 合约
- 赚币
- 法币
- 策略

不同账户之间通过“划转”转移模拟 USDT。

## 本地运行

推荐使用本地 HTTP Server，而不是直接双击 `index.html`：

```bash
python -m http.server 8080
```

打开：

```text
http://localhost:8080
```

页面需要联网访问 Binance 公共行情接口和 WebSocket。
