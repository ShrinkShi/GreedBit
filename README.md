# GreedBit

GreedBit 是一个面向网页与 Bilibili Toy 场景设计的虚拟货币交易模拟器。

项目参考主流数字资产交易终端的交互结构，但不连接真实交易所、不涉及真实资金，也不提供任何投资建议。目标是把行情、K 线、盘口、下单、持仓与后续合约机制做成一个有游戏性、同时尽量符合真实交易逻辑的模拟系统。

当前版本：**v0.0.1**

## v0.0.1 已实现

- BTC / ETH / SOL / DOGE 四个模拟交易对
- 类交易所暗色交易终端布局
- 实时模拟行情
- K 线图与 OHLC 查看
- 1m / 5m / 15m 模拟周期切换
- 1x / 5x / 20x 行情加速
- 模拟买卖盘口
- 市价买入 / 卖出
- 限价委托
- 自动触发限价成交
- 撤单
- 成交记录
- USDT 模拟余额
- 币种持仓、总资产估值与浮动盈亏
- 桌面端与移动端基础响应式布局

## 核心设计：K 线不是一次生成的

GreedBit 当前最重要的实现原则，是避免常见模拟交易小游戏直接随机生成完整 OHLC 蜡烛的问题。

行情引擎会持续生成价格 tick，当前 K 线再由这些连续价格动态聚合：

```text
连续价格 Tick
      ↓
K 线聚合器
      ↓
Open  = 周期内第一个价格
High  = 周期内实际出现过的最高价格
Low   = 周期内实际出现过的最低价格
Close = 当前最新价格
```

因此当前蜡烛的实体和上下影线会随着行情逐步形成。只有周期结束后，这根 K 线才会被封盘并进入历史数据。

历史 K 线同样由连续 tick 聚合生成，而不是分别随机生成 Open / High / Low / Close。

## 当前行情模型

v0.0.1 使用纯前端本地模拟行情，主要由以下因素共同驱动：

- 随机价格扰动
- 短期动量
- 阶段性趋势状态
- 偶发价格冲击
- 轻微均值回归

这仍然只是早期市场模型。当前盘口也属于视觉与交易逻辑模拟，并非真正由完整订单簿撮合产生价格。

## 运行方式

当前项目没有构建步骤，也没有第三方运行依赖。

直接打开仓库根目录的：

```text
index.html
```

即可运行。

也可以使用任意静态 HTTP Server，例如：

```bash
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

## 后续方向

计划逐步加入：

- 更真实的市场状态机：震荡、趋势、牛市、熊市、瀑布等
- 新闻与突发事件系统
- 虚构高波动币种与特殊市场事件
- 插针、流动性变化与异常波动
- 永续合约
- 做多 / 做空
- 杠杆与保证金
- 强制平仓
- 更真实的订单簿
- 模拟交易者、做市商、机构和鲸鱼
- 由订单撮合与成交真正驱动价格
- 排行榜、存档与 Bilibili Toy 平台能力接入

长期目标是让价格尽可能由市场参与者和订单行为产生，而不是直接随机决定最终 K 线结果。

## 关于 Bilibili Toy

GreedBit 的前端结构会尽量保持为可静态部署形式，以便后续打包为 Bilibili Toy 网页互动作品。当前版本尚未接入 Bilibili 用户身份、云存档或排行榜接口。
