# GreedBit

GreedBit 是一个本地运行的虚拟货币交易模拟器。BTC/USDT 与 ETH/USDT 使用真实公开市场行情；账户、订单、杠杆、强平、资产划转等交易规则仍是本地模拟。

当前版本：**v0.0.11**

## v0.0.9 重点

### 图表交互

- 横轴与纵轴缩放命中区彻底分离：
  - 鼠标位于价格轴滚轮：只缩放纵轴。
  - 鼠标位于时间轴滚轮：只缩放横轴。
  - 鼠标位于主图区域滚轮：横纵轴同时缩放。
- 支持上下、左右拖动画布。
- 价格轴最低固定为 `0`。
- 双击恢复默认视图。
- 交易成交后在 K 线上显示 `B / S` 标记。
- 右键菜单支持：
  - 重置图表视图
  - 复制当前价格
  - 锁定 / 解锁十字光标
  - 显示 / 隐藏成交标记
  - 打开图表设置

### 图表设置

图表工具栏增加图标式设置按钮，设置面板包含：

- 商品代码：K 线主体、边框、影线、涨跌颜色、精度、时区
- 状态行：标题、OHLC、变化值、成交量等
- 比例和线条：价格标签、K 线倒计时、高低点、成交标记、日期 / 时间格式
- 版面：背景、网格、十字线、上下边距、右侧空白 K 线数量

设置存放于浏览器 `localStorage`。

### 本地管理员

内置本地开发管理员：

```text
账号：admin
密码：123456
```

管理员登录后，顶部“资产”右侧出现“管理”入口，可查看：

- 本地账户数量
- 真实行情连接状态
- 已加载真实资讯数量
- LocalStorage 占用
- 本地注册账号和存档状态

> 这是前端硬编码的本地开发账号，任何人都能从源码中看到密码，**绝不能作为公开部署时的真实管理员认证**。

### 真实行情资讯

行情页不再生成随机新闻。v0.0.9 默认读取 **CoinDesk 官方 RSS**，并通过浏览器跨域代理回退方案加载真实加密货币资讯。

- 快讯标题、摘要、时间和来源来自真实 RSS。
- 点击标题可打开原始新闻页面。
- 根据文本自动分类 BTC / ETH / 监管 / 机构 / 市场 / 技术等。
- 用户仍可点击“利好 / 利空”。
- 当前尚无多人后端，因此“社区倾向”仍是本地模拟基线，不冒充真实在线用户投票。

AiCoin 官方也提供快讯 API，但需要 AccessKeyId 和签名密钥。当前纯前端版本不会把这类密钥写进公开源码，等本地 Node.js 后端上线后再接入。

## 真实 BTC / ETH 市场行情

当前仅保留：

- BTC/USDT
- ETH/USDT

行情来源：

- Binance Spot REST API：历史 K 线、24H 统计、盘口深度
- Binance Spot WebSocket：实时成交与 24H ticker

历史 K 线直接读取真实 OHLCV；当前 K 线由实时成交继续更新。10 分钟周期由真实 5 分钟 K 线聚合。

如果 Binance 在当前网络或地区不可访问，GreedBit 会显示行情连接失败，并停止依赖价格的下单，不会回退到随机假行情。

## 交易功能

### 现货

- 市价 / 限价买入和卖出
- 不支持做空
- 独立现货账户
- 现货限价委托显示在 K 线图
- 成交音效
- 成交 K 线 B / S 标记

### 合约

- 开多 / 开空
- 全仓 / 逐仓
- 1X–200X 杠杆
- 限价委托
- 止盈 / 止损
- 强制平仓
- 模拟资金费率
- 历史仓位与财务流水
- 成交音效和 B / S 标记

> 合约只是游戏规则模拟。市场价格虽然来自真实现货行情，但强平、手续费、资金费率和风险参数不代表任何真实交易所。

## 本地运行

推荐使用本地 HTTP Server：

```bash
python -m http.server 8080
```

然后打开：

```text
http://localhost:8080
```

页面需要联网访问 Binance 行情接口、WebSocket、CoinDesk RSS 以及 RSS 跨域代理。

## v0.0.10 新增

- 合约「概况」页：BTC/ETH 项目资料、估算市值、供应量、资源链接。
- 合约「数据」页：接入 Binance USDⓈ-M Futures 公共数据，展示持仓量、主动买卖量、大户账户/持仓多空比、全市场多空比、资金费率与溢价指数。
- 盘口 / 实时成交切换：实时成交流使用 Binance Futures `aggTrade`。
- 策略交易入口：现货网格、合约网格、合约马丁格尔的本地模拟配置。
- 高级委托：计划、跟踪、分时（TWAP）本地模拟委托，可在当前委托中撤销。
- 高级委托与策略仍属于模拟交易逻辑，不会向真实交易所发送订单。

### 本地版限制

- 管理员通知仍使用 `localStorage`，只能覆盖同一浏览器里注册过的本地账号；公开部署必须迁移到后端消息系统。
- 当前完整界面仍以中文为主，English 选项优先切换全局导航与账户相关菜单，后续后端化时再做完整 i18n。
- 折算汇率会尝试从公开汇率接口刷新；接口不可用时使用缓存/内置近似汇率，不影响真实 BTC/ETH USDT 市场价格。
