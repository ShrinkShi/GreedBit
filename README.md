# GreedBit

GreedBit 是一个面向网页与 Bilibili Toy 场景设计的虚拟货币交易模拟器。

项目参考主流数字资产交易终端的交互结构，但不连接真实交易所、不涉及真实资金，也不提供任何投资建议。目标是把行情、K 线、盘口、永续合约、杠杆、保证金、持仓与强制平仓做成一个有游戏性、同时尽量符合真实交易逻辑的模拟系统。

## 核心设计：K 线不是一次生成的

GreedBit 最重要的实现原则之一，是避免常见模拟交易小游戏直接随机生成完整 OHLC 蜡烛的问题。

行情引擎会持续生成价格 Tick，当前 K 线再由这些连续价格动态聚合：

```text
连续价格 Tick
      ↓
K 线聚合器
      ↓
Open  = 周期内第一个价格
High  = 周期内实际出现过的最高价格
Low   = 周期内实际出现过的最低价格
Close = 当前最新价格
```

因此当前蜡烛的实体和上下影线会随着行情逐步形成。只有周期结束后，这根 K 线才会被封盘并进入历史数据。

## 强平机制

v0.0.3 开始，仓位风险直接连接行情 Tick。

```text
开仓
 ↓
记录方向 / 杠杆 / 保证金 / 开仓价
 ↓
计算预计强平价
 ↓
行情持续生成 Tick
 ↓
实时计算标记价格和未实现盈亏
 ↓
价格触及强平价
 ↓
强制平仓并结算账户余额
```

逐仓仓位主要以该仓位自身保证金承担风险；全仓模式还会使用账户剩余可用余额作为风险缓冲，因此两者的预计强平价不同。

当前强平模型是游戏化近似模型，并不宣称完全复刻任一真实交易所的风险引擎。

## 当前行情模型

行情仍使用纯前端本地模拟，主要由以下因素共同驱动：

- 随机价格扰动
- 短期动量
- 阶段性趋势状态
- 偶发价格冲击
- 轻微均值回归

当前盘口属于视觉与交易逻辑模拟，并非真正由完整订单簿撮合产生价格。

## 运行方式

项目没有构建步骤，也没有第三方运行依赖。

推荐使用静态 HTTP Server：

```bash
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

也可以直接打开 `index.html`。

## 项目结构

```text
GreedBit/
├─ index.html    # 页面结构
├─ styles.css    # 交易终端界面样式
├─ app.js        # 行情、K线、账户与永续合约逻辑
├─ README.md     # 项目说明
├─ CHANGELOG.md  # 版本记录
└─ VERSION       # 当前版本号
```

从 v0.0.3 开始不再把所有代码塞进单个 HTML 文件，以降低后续维护成本，同时仍保持纯静态部署结构，便于打包到 Bilibili Toy。

长期目标是让价格尽可能由市场参与者和订单行为产生，而不是直接随机决定最终 K 线结果。

## 关于 Bilibili Toy

GreedBit 保持纯 HTML / CSS / JavaScript 静态结构，便于后续直接打包为 Bilibili Toy 网页互动作品。当前版本尚未接入 Bilibili 用户身份、云存档或排行榜接口。
