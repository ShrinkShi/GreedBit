# GreedBit

GreedBit 是一个面向 **Bilibili Toy** 的纯前端虚拟货币交易模拟器。项目使用公开市场行情驱动模拟交易，同时保留原创平台币、赚币、手续费抵扣、杠杆、强平等游戏化交易机制。

当前版本：**v0.0.15**

## 项目边界

GreedBit 长期保持纯前端：

- 不建设自有后端或自有数据库。
- 不接入真实交易账户，不发送真实订单。
- 不保存交易所 API Key、Secret 等敏感凭证。
- 本地账号、资产、订单、持仓、通知、头像、赚币记录和设置默认保存在浏览器 `localStorage`。
- 如未来需要少量跨设备存档，只考虑 Bilibili Toy 官方平台能力，不建设自有服务端。

### 行情来源

BTC、ETH、SOL、DOGE、BNB、FIL、TRX、ZEC 优先直接读取 Binance 无密钥公共市场接口。

BTW、牛来、龙虾优先尝试可用的公开市场源；如果当前公共源无法取得该交易对，会明确显示为“参考模拟行情”，使用 BTC / ETH 走势相关模型生成参考 K 线，不把模拟数据冒充真实市场数据。

GREED 不上链、没有真实外部市场，因此始终属于 **GreedBit 内部模拟行情**。其价格模型由：

- BTC 市场变化
- ETH 市场变化
- 更高的山寨币式 Beta
- 独立随机波动
- 行情页随机出现的 GREED 模拟新闻事件

共同驱动。GREED 的波动率刻意高于 BTC / ETH。

## 交易手续费

普通交易费率：

- Maker：**0.020%**
- Taker：**0.060%**

实现规则：市价单按 Taker 费率；正常挂入盘口并成交的限价单按 Maker 费率。

如果用户的**现货账户**中持有足够 GREED，可自动使用 GREED 按实时价格抵扣完整手续费：

- GREED Maker：**0.001%**
- GREED Taker：**0.002%**

GREED 不足以支付完整折扣手续费时，自动回退为普通 USDT 手续费。赚币账户、合约仓位中的 GREED 不计入手续费抵扣余额。

## 现货账户与总资产

现货账户可以持有全部已接入币种，而不仅是 USDT / BTC / ETH。

总账户估值按照：

```text
USDT 与现金类余额
+ 各币种数量 × 实时价格 × (1 - 市价卖出 Taker 手续费)
+ 合约账户权益
+ 赚币账户净估值
```

计算。

主页和资产总览同时显示每日盈亏：

- 盈利：绿色
- 亏损：红色
- 0.00%：灰色

入金和出金会从每日盈亏中剔除，避免把充值误算为盈利。

## 赚币

顶部导航新增“赚币”页面。所有现货币种都可以从现货账户转入赚币账户，利息**每小时结算一次并自动复投**。

年化利率：

| 资产 | 年化 |
| --- | ---: |
| USDT | 4% |
| USDT 前 500 | 活动 10% |
| BTC | 1% |
| ETH | 1.6% |
| SOL | 1.8% |
| DOGE | 3% |
| GREED | 4% |
| 其他已接入币种 | 5% |

赚币账户中的币可随时赎回现货账户。

## 市场资讯

“行情”页面继续定位为新闻资讯流，不做价格行情总览。

新闻主源：

- CoinDesk RSS
- CNBC Investing
- CNBC Top News 备用

纯前端版本会尝试直连与多个浏览器跨域通道，并缓存最近一次成功新闻，避免临时网络故障导致整页空白。

英文新闻在中文界面提供“翻译”按钮；切换到 English 后，中文 GREED 模拟新闻也提供翻译按钮。翻译按需触发并在本地缓存，不会自动批量消耗免费翻译额度。

行情页还会定期随机插入明确标注为 **GREED 模拟事件** 的虚拟新闻，这些事件可以短期影响 GREED 的内部模拟价格，但不会改变 BTC、ETH 等真实市场价格。

## 设计与性能

v0.0.15 开始建立统一的界面设计 Token：8px 间距网格、统一圆角、表单 Focus Ring、错误状态、暗色滚动条和金融数字等宽字体。

关键性能策略：

- 历史委托、成交记录、财务记录等长表格超过阈值后启用原生虚拟滚动，只渲染可视区域附近 DOM。
- Binance WebSocket 消息优先在 `Web Worker` 中解析并按批次发送给主线程。
- 主线程行情 DOM 更新使用节流 + `requestAnimationFrame`，避免逐笔成交直接触发完整重绘。
- Worker 不可用时自动退回主线程批处理，不中断行情。
- 切换交易对及本地页面首次进入使用与最终布局一致的深色 Skeleton，而非全屏 Loading。
- 保证金、强平价、标记价、资金费率等术语提供延迟 Tooltip。

图表深色背景下，默认上涨色保持 `#3dbb83`；默认下跌色调整为 `#ff6b78`，用于提升关键红色数据与 K 线的对比度。

## 主页视觉

主页使用 `assets/mammon-home.webm` 作为透明动态立绘。立绘固定在右下视觉区，左侧功能与资产组件和右侧立绘采用硬分栏，避免控件遮挡人物。

旧的非透明 `mammon-home.mp4` 已移除。

## 浏览器图标

导航栏仍使用高清 `assets/greedbit-logo.png`；浏览器标签页 favicon 使用独立多尺寸 `assets/favicon.ico`，避免高清 Logo 在标签页中被裁切或显得过大。

## Bilibili Toy

GreedBit 使用单入口 `index.html`，CSS / JavaScript / 图片 / WebM / Worker 全部使用相对路径，不依赖自建服务端路由。

Windows PowerShell 打包：

```powershell
.\tools\build-toy.ps1
```

生成：

```text
dist-toy/
GreedBit-toy.zip
```

Toy 正式发布前仍需在真实 Preview 环境验证 Binance REST / WebSocket、HTX 公共接口、RSS/CORS 通道、WebM 播放和 Web Worker 兼容性。

## 本地运行

```bash
python -m http.server 8080
```

浏览器打开：

```text
http://localhost:8080
```
