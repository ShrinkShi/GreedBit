# GreedBit

GreedBit 是一个面向网页与 Bilibili Toy 场景设计的虚拟货币交易模拟器。项目参考主流数字资产交易终端的交互结构，但不连接真实交易所、不涉及真实资金，也不构成投资建议。

当前版本：**v0.0.6**

## v0.0.6 重点

### K 线与图表
- 实时 K 线严格按真实时间分桶；5 分钟周期需要现实 5 分钟才封盘一根。
- 当前价格标签下方直接显示本根 K 线剩余时间。
- 时间轴与价格轴独立缩放。
- 可拖动查看历史，也可向右拖出未来空白区域。
- 图表、盘口、交易区和底部持仓区支持拖拽调整尺寸。
- 限价委托显示为图表水平线。

### 永续合约交易
- 市价 / 限价开多、开空。
- 全仓 / 逐仓。
- 杠杆通过独立弹窗在 1X–200X 间连续调整。
- 保证金比例滑块支持任意整数百分比，0/25/50/75/100 为快捷点。
- 止盈止损改为复选框控制；勾选后才显示独立的止盈与止损触发价。
- 强平、止盈、止损、减仓、全平、资金费率结算均保留。

### 账户与资产
- 本地模拟注册 / 登录。
- “买币”打开模拟购买 USDT 弹窗。
- 支持模拟出金。
- 账户统计累计：入金、出金、已实现盈利、已实现亏损、手续费、资金费率收支、净已实现收益、爆仓次数和成交次数。
- 账户状态保存在当前浏览器 localStorage。

### 行情资讯与随机事件
- 行情资讯侧栏提供随机市场新闻。
- 同时存在真实消息与虚假消息。
- 消息初始为“待核实”，随后会变为“已确认”或“已证伪”。
- 新闻不会直接画 K 线，而是暂时改变市场买卖倾向和波动率。
- 假消息被证伪后会产生一段反向价格修正压力。

## 核心原则：价格过程先于 K 线

GreedBit 不直接随机生成完整 OHLC。市场引擎持续产生价格 Tick，K 线只负责按选定时间周期聚合：

```text
市场状态 / 随机扰动 / 新闻事件
                ↓
              Tick
                ↓
         K 线时间分桶聚合
                ↓
 Open / High / Low / Close
```

因此新闻、止损、限价单和强平都作用于实时价格过程，而不是直接修改最终蜡烛形态。

## 本地运行

项目目前是纯静态前端，可直接在电脑本地测试：

```bash
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

## 当前限制

- 行情仍由本地统计市场模型驱动，不是真实订单簿撮合结果。
- 不同浏览器实例并不共享同一市场。
- 登录和账户数据使用 localStorage，仅适用于原型测试。
- 新闻完全为游戏内随机生成内容，不代表真实世界新闻。
- 风险限额、强平价、资金费率等为模拟近似规则，不代表任何真实交易所。

## 后续方向

下一阶段会逐步迁移到本地后端：

- Node.js / TypeScript Server Alpha。
- 服务端统一生成 Tick、K 线与新闻事件。
- 账户、委托、仓位由服务端管理。
- WebSocket 向前端推送统一行情。
- 后续再加入更真实的订单簿、做市商、散户、鲸鱼和机构行为。
