# GreedBit

GreedBit 是一个本地运行的虚拟货币交易模拟器，目标是在网页中模拟现货、永续合约、账户划转、新闻事件、K 线和风险管理。

当前版本：**v0.0.7**

## v0.0.7 重点

### 多页面交易终端

顶部导航重构为：

- 主页
- 行情
- 交易（现货）
- 合约
- 资产

现货与合约共享同一套模拟行情、K 线和盘口，但使用各自独立的账户和订单系统。

### 现货交易

- 只允许买入和卖出，不支持做空
- 市价 / 限价
- 独立现货账户 USDT
- BTC / ETH / SOL / DOGE 持仓
- 现货限价委托显示在 K 线图上
- 现货订单、成交记录
- 简化成本价与已实现盈亏统计

### 合约交易

保留此前的：

- 开多 / 开空
- 全仓 / 逐仓
- 1X–200X 杠杆
- 限价委托
- 止盈 / 止损
- 强制平仓
- 资金费率
- 历史仓位
- 财务流水

### 分账户资产

资产拆分为：

- 现货账户
- 合约账户
- 赚币账户
- 法币账户
- 策略账户

不同账户之间的 USDT 不能直接混用，必须通过“划转”操作转入目标账户。

资产页支持：

- 总览
- 现货
- 合约
- 赚币
- 法币
- 策略
- 模拟入金 / 出金
- 账户间 USDT 划转

旧版本单一合约余额会在加载 v0.0.7 时自动迁移到合约账户。

### 图表交互升级

- 图表可同时上下、左右拖动
- 横坐标和纵坐标连续缩放
- 大幅放宽原来的缩放限制
- 双击恢复默认视图
- 可向未来空白区域继续拖动
- 未来区域仍显示时间刻度
- 当前价格标签下方显示下一根 K 线倒计时
- 现货 / 合约限价委托都可画在图表中

### 行情资讯

行情页改为完整时间线快讯界面：

- 随机真消息 / 假消息
- 待核实 / 已确认 / 已证伪
- 利好 / 利空投票
- 显示模拟其他用户的市场评价比例
- 快讯会改变市场漂移和波动率
- 假消息证伪后可能出现反向修正

> 当前没有多人后端，因此“其他用户评价”是本地模拟数据，不是真实联网投票。

### 币种选择器

币种选择改成交易所式下拉面板，目前只保留：

- BTC/USDT
- ETH/USDT
- SOL/USDT
- DOGE/USDT

暂不增加新币种。

### 成交音效

市价成交、限价成交和平仓会通过 Web Audio API 播放短促成交提示音，不依赖外部音频资源。

## K 线原则

GreedBit 不直接随机生成完整 OHLC。实时价格先产生 Tick，再由 Tick 聚合：

```text
Tick
 ↓
Open / High / Low / Close
 ↓
当前 K 线持续生长
 ↓
周期结束后封盘
```

5 分钟 K 线使用真实 5 分钟分桶，1 小时 K 线使用真实 1 小时分桶。

## 本地运行

推荐：

```bash
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```
