# GreedBit

GreedBit 是一个面向网页与 Bilibili Toy 场景设计的虚拟货币交易模拟器。

项目参考主流数字资产交易终端的交互结构，但不连接真实交易所、不涉及真实资金，也不提供任何投资建议。目标是把行情、K 线、盘口、下单、持仓与后续合约机制做成一个有游戏性、同时尽量符合真实交易逻辑的模拟系统。

当前版本：**v0.0.2**

### K 线与行情交互

支持以下视图：

- 分时
- 1 分钟
- 3 分钟
- 5 分钟
- 15 分钟
- 30 分钟
- 1 小时
- 2 小时
- 4 小时
- 8 小时
- 1 日
- 3 日
- 1 周
- 1 月

图表支持：

- 鼠标滚轮放大 / 缩小
- 按住鼠标拖动查看历史 K 线
- 双击图表回到最新行情
- 鼠标悬停查看 OHLC
- 当前未封盘蜡烛实时更新

GreedBit 仍坚持同一个核心原则：**K 线不是一次性随机生成完整 OHLC，而是由连续价格 tick 聚合形成。**

```text
连续价格 Tick
      ↓
时间周期聚合器
      ↓
Open  = 周期内第一个价格
High  = 周期内实际出现过的最高价格
Low   = 周期内实际出现过的最低价格
Close = 当前最新价格
```

为了让网页原型可以快速展示分钟到月级别周期，当前版本采用**加速模拟时间**。周期聚合关系是真实的，但并不要求玩家在现实世界等待一个月才能看到月线形成。

v0.0.2 增加了本地演示登录 / 注册系统：

## 当前行情模型

行情由纯前端本地模拟模型生成，主要包含：

- 随机价格扰动
- 短期动量
- 阶段性趋势
- 偶发冲击
- 轻微均值回归

当前盘口仍属于模拟深度，并不会反向驱动成交价格。后续版本会逐步升级为更真实的市场状态机与订单簿撮合模型。

## 运行方式

当前项目没有构建步骤，也没有第三方运行依赖。

直接打开：

```text
index.html
```

即可运行。

也可以使用静态 HTTP Server：

```bash
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

## 关于 Bilibili Toy

GreedBit 会尽量保持可静态部署与轻量打包，以便后续作为 Bilibili Toy 网页互动作品发布。当前尚未接入 Bilibili 用户身份、云存档或排行榜接口。
