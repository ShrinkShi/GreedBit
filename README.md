# GreedBit

GreedBit 是一个面向网页与 Bilibili Toy 场景设计的虚拟货币交易模拟器。

项目参考主流数字资产交易终端的交互结构，但不连接真实交易所、不涉及真实资金，也不提供任何投资建议。目标是把行情、K 线、盘口、永续合约、杠杆、保证金、委托、持仓与风险控制做成一个有游戏性、同时尽量符合真实交易逻辑的模拟系统。

当前版本：**v0.0.5**

## v0.0.5 重点更新

### K 线时间逻辑修正

v0.0.5 不再使用加速 `simTime` 驱动实时 K 线，而是直接使用浏览器真实 Unix 时间分桶。

因此：

- 1 分钟周期：现实 1 分钟封一根 K 线
- 5 分钟周期：现实 5 分钟封一根 K 线
- 10 分钟周期：现实 10 分钟封一根 K 线
- 1 小时周期：现实 1 小时封一根 K 线
- 其他周期同理

当前 K 线仍然由连续 Tick 动态更新 Open / High / Low / Close，只有跨越真实周期边界时才封盘。

图表右上角新增“距离下一根 K 线”的实时倒计时。

### 图表交互

支持：

- 分时
- 1分钟 / 3分钟 / 5分钟 / 10分钟 / 15分钟 / 30分钟
- 1小时 / 2小时 / 4小时 / 8小时
- 1日 / 3日 / 1周 / 1月
- 横坐标时间轴
- 鼠标悬停查看 OHLC 与时间
- 鼠标拖动查看历史行情
- 可继续向未来方向拖动，右侧不再强制贴住最新 K 线
- 双击恢复默认视图
- 时间轴 / 主图滚轮缩放横轴
- 在右侧价格轴滚轮缩放纵轴价格范围
- 当前限价委托直接绘制在 K 线图中

### 保证金滑动条

保证金百分比滑动条从原来的固定 0 / 25 / 50 / 75 / 100 五档，改为：

- 0% 到 100% 任意整数百分比连续滑动
- 0 / 25 / 50 / 75 / 100 位置保留快捷圆点
- 点击快捷圆点可立即跳转到对应百分比

### 可拖动布局

桌面端新增可拖动分隔线：

- 图表 ↔ 盘口
- 盘口 ↔ 交易区
- 图表区域 ↔ 底部持仓 / 委托区域

可以根据屏幕尺寸和使用习惯动态调整工作区大小。

### 操作通知

右上角新增交易所风格操作通知：

- 登录 / 注册结果
- 市价开仓
- 限价委托提交
- 限价委托成交
- 撤单
- 手动平仓 / 减仓
- 止盈 / 止损
- 强制平仓
- 资金费率结算

通知会自动消失，也可手动关闭。

## 运行方式

GreedBit v0.0.5 仍然是纯前端项目，不需要后端即可运行。

推荐在项目目录启动静态服务器：

```bash
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

也可以直接打开 `index.html`，但后续接入本地 GreedBit Server 时会以 HTTP 方式运行。

## 下一阶段

当前先以用户电脑作为本地开发服务器。后续计划进入前后端分离：

```text
GreedBit Web
      ↓ HTTP / WebSocket
GreedBit Server
      ↓
统一行情 / 用户资产 / 委托 / 持仓 / 市场状态
```

优先方向：

- Node.js / TypeScript 本地后端
- WebSocket 实时行情
- 多客户端共享同一市场
- 账户与资产持久化
- 服务端委托 / 强平 / 止盈止损
- 更真实的市场状态机
- 新闻与突发事件系统
- 更真实的订单簿与模拟交易者
